Seal a file for several people at once;
any one of them opens it.

A sealed file is a header of recipient stanzas over a streaming payload. A passphrase, a public key, an SSH key the reader already has, a post-quantum hybrid, or a key inside a token — all in one header. No key ring, no trust model, no key server: a format, not a vault.
