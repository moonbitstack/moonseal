The guide — one file, several readers, no key server

A sealed file is a header of recipient stanzas over a streaming payload. Every stanza wraps the same sixteen-byte file key, so a file addressed to four people is one file and any one of them opens it. This page walks through every recipient type moonseal supports, the streaming path, the armored text form, and how to add your own recipient type. Each snippet compiles, and each printed block is the output of that snippet run as-written.

Setup

Add the library and the randomness source, then declare the packages you use in moon.pkg.

# moon.mod name = "your-app" source = "." import { "moonbitstack/moonseal", "moonbitstack/moonseed", }
# moon.pkg (the package that uses moonseal) import { "moonbitstack/moonseal", "moonbitstack/moonseal/spec", "moonbitstack/moonseal/x25519", "moonbitstack/moonseal/scrypt", "moonbitstack/moonseal/ssh", "moonbitstack/moonseal/mlkem768x25519", "moonbitstack/moonseal/p256tag", "moonbitstack/moonseal/mlkem768p256tag", "moonbitstack/moonseed", }
Randomness. Every call that seals takes a random~ source. In a real program pass @system.source from moonbitstack/moonseed/system. The snippets below instead pin a deterministic source with @moonseed.Replay::new(Bytes::make(n, 0xNN)) so the printed output is reproducible and matches what you see here. Swap in @system.source and the bytes change but the shape does not. Core packages such as @utf8 and @bytes need no import.

1 · A passphrase

The simplest recipient is a passphrase. @scrypt.Recipient::new derives a key from the phrase with scrypt; log_n sets the work factor (10 is fine for a demo, 14–18 for real use). No keys to manage — the reader supplies the same phrase to open.

moonbit
fn seal_with_passphrase() -> Unit raise @spec.Refused { let random = @moonseed.Replay::new(Bytes::make(128, 0x21)) let file = @moonseal.seal( [@scrypt.Recipient::new("correct horse battery staple", log_n=10)], b"the quick brown fox\n", random=random, ) let opened = @moonseal.open( [@scrypt.Identity::new("correct horse battery staple")], file, ) println("sealed: " + file.length().to_string() + " bytes") println("opened: " + @utf8.decode_lossy(opened)) }
output
--- passphrase ---
sealed: 202 bytes
opened: the quick brown fox

2 · A key pair, then a recipient

For public-key use, generate an X25519 identity with @x25519.Identity::generate. Hand out identity.public() (an @spec.Recipient) to seal; keep identity (an @spec.Identity) to open. code() renders the bech32 age string; Identity::of / Recipient::of parse one back from text.

moonbit
fn key_pair() -> Unit raise @spec.Refused { let random = @moonseed.Replay::new(Bytes::make(64, 0x42)) let alice = @x25519.Identity::generate(random=random) catch { _ => abort("no randomness") } println(alice.code()) // AGE-SECRET-KEY-… println(alice.public().code()) // age1… } fn seal_to_recipient() -> Unit raise @spec.Refused { let kp = @moonseed.Replay::new(Bytes::make(64, 0x42)) let alice = @x25519.Identity::generate(random=kp) catch { _ => abort("no") } let seal_rand = @moonseed.Replay::new(Bytes::make(64, 0x21)) let file = @moonseal.seal([alice.public()], b"the quick brown fox\n", random=seal_rand) catch { _ => abort("cannot seal") } println("sealed: " + file.length().to_string() + " bytes") println("opened: " + @utf8.decode_lossy(@moonseal.open([alice], file))) }
output

3 · An SSH key the reader already has

If the reader already holds an SSH key, seal to its public half with @ssh.Recipient::of and open with @ssh.Identity::of on the private half. Ed25519 and RSA are both accepted. kind() reports the algorithm; fingerprint() returns age's short SSH fingerprint.

moonbit
fn ssh_example() -> Unit raise @spec.Refused { let recipient = @ssh.Recipient::of( "ssh-ed25519 AAAAC3NzaC1lZDI1NTE5AAAAIFi1otykT1YoBR3We0Xf/eNmdx4W32NHFBqQo+b4DqHM moonseal guide", ) catch { _ => abort("not an SSH key") } println("kind: " + recipient.kind()) println("fingerprint: " + recipient.fingerprint()) let seal_rand = @moonseed.Replay::new(Bytes::make(64, 0x21)) let file = @moonseal.seal([recipient], b"the quick brown fox\n", random=seal_rand) catch { _ => abort("cannot seal") } let priv_text : String = "-----BEGIN OPENSSH PRIVATE KEY-----\n" + "b3BlbnNzaC1rZXktdjEAAAAABG5vbmUAAAAEbm9uZQAAAAAAAAABAAAAMwAAAAtzc2gtZW\n" + "QyNTUxOQAAACBYtaLcpE9WKAUd1ntF3/3jZnceFt9jRxQakKPm+A6hzAAAAJhGzMSTRszE\n" + "kwAAAAtzc2gtZWQyNTUxOQAAACBYtaLcpE9WKAUd1ntF3/3jZnceFt9jRxQakKPm+A6hzA\n" + "AAAEAPBk/Wd8ZajsZ4fKz8ITJwWncXCrmdlyQVg4nGcvOHRVi1otykT1YoBR3We0Xf/eNm\n" + "dx4W32NHFBqQo+b4DqHMAAAADm1vb25zZWFsIGd1aWRlAQIDBAUGBw==\n" + "-----END OPENSSH PRIVATE KEY-----" let identity = @ssh.Identity::of(priv_text) println("opened: " + @utf8.decode_lossy(@moonseal.open([identity], file))) }

4 · A post-quantum hybrid key

@mlkem768x25519 pairs X25519 with ML-KEM-768. A sealed file stays openable by a classical reader, but resists a future quantum adversary. The API is identical to the plain key pair: generate, hand out .public(), open with the identity.

moonbit
fn post_quantum() -> Unit raise @spec.Refused { let kp = @moonseed.Replay::new(Bytes::make(128, 0x7a)) let after = @mlkem768x25519.Identity::generate(random=kp) catch { _ => abort("no") } println(after.code()) // AGE-SECRET-KEY-PQ-… let seal_rand = @moonseed.Replay::new(Bytes::make(128, 0x21)) let file = @moonseal.seal([after.public()], b"still secret\n", random=seal_rand) catch { _ => abort("no") } println("opened: " + @utf8.decode_lossy(@moonseal.open([after], file))) }
output
--- post-quantum ---
AGE-SECRET-KEY-PQ-10FA857N60FA857N60FA857N60FA857N60FA857N60FA857N60FAQCETL9H
opened: still secret

5 · A tagged recipient (key held in hardware)

A tagged recipient names a key by a short tag instead of a full public key, so the sealed file does not reveal which key opens it. @p256tag uses a P-256 point under the tag. Generate the identity, publish .public() (the age1tag1… string), open with the identity.

moonbit
fn tagged() -> Unit raise @spec.Refused { let kp = @moonseed.Replay::new(Bytes::make(128, 0x99)) let device = @p256tag.Identity::generate(random=kp) catch { _ => abort("no") } println(device.public().code()) // age1tag1… let seal_rand = @moonseed.Replay::new(Bytes::make(128, 0x21)) let file = @moonseal.seal([device.public()], b"for the key on the desk\n", random=seal_rand) catch { _ => abort("no") } println("opened: " + @utf8.decode_lossy(@moonseal.open([device], file))) }
output
--- tagged ---
age1tag1q0wuyawkyvqmwdp5lwhemmeugtz06kx0na53rswl7v64we6t5rv5vp064z0
opened: for the key on the desk

6 · A tagged post-quantum recipient

@mlkem768p256tag combines the tagged P-256 scheme with ML-KEM-768: the key stays unnamed in the header and the file is quantum-resistant. The public code is long because it embeds the ML-KEM ciphertext; the workflow is unchanged.

fn tagged_post_quantum() -> Unit raise @spec.Refused { let kp = @moonseed.Replay::new(Bytes::make(128, 0xbb)) let device = @mlkem768p256tag.Identity::generate(random=kp) catch { _ => abort("no") } println(device.public().code()) // age1tagpq1… (long) let seal_rand = @moonseed.Replay::new(Bytes::make(128, 0x21)) let file = @moonseal.seal([device.public()], b"for the key on the desk\n", random=seal_rand) catch { _ => abort("no") } println("opened: " + @utf8.decode_lossy(@moonseal.open([device], file))) }

7 · Streaming a file larger than memory

When the payload does not fit in memory, seal and open through a source and a sink. @moonseal.BytesSource and @moonseal.BytesSink are in-memory stand-ins; replace them with a file or network stream in production. The format is byte-identical to the buffered path, in 64 KiB chunks.

moonbit
fn stream_example() -> Unit raise @spec.Refused { let sink = @moonseal.BytesSink::new() let seal_rand = @moonseed.Replay::new(Bytes::make(128, 0x21)) @moonseal.seal_stream( sink, [@scrypt.Recipient::new("correct horse battery staple", log_n=10)], @moonseal.BytesSource::new(b"the quick brown fox\n"), random=seal_rand, ) catch { _ => abort("no") } let file = sink.bytes() let open_sink = @moonseal.BytesSink::new() @moonseal.open_stream( open_sink, [@scrypt.Identity::new("correct horse battery staple")], @moonseal.BytesSource::new(file), ) catch { _ => abort("no") } println("opened: " + @utf8.decode_lossy(open_sink.bytes())) }
output
--- stream ---
opened: the quick brown fox

8 · Armor: the file as text

When the ciphertext must travel through a text-only channel (chat, email, a paste), seal_armored wraps the age file in a PEM-style envelope. open_armored reads it back. The body is the same age v1 stream, base64-encoded.

moonbit
fn armor_example() -> Unit raise @spec.Refused { let seal_rand = @moonseed.Replay::new(Bytes::make(128, 0x21)) let text = @moonseal.seal_armored( [@scrypt.Recipient::new("correct horse battery staple", log_n=10)], b"the quick brown fox\n", random=seal_rand, ) catch { _ => abort("no") } println(text) // the armored age file }

9 · Your own recipient type

A recipient is two traits: @spec.Recipient wraps the file key into a stanza, and @spec.Identity unwraps it. Implement both and the type drops into any seal / open call. The example below is a transparent stand-in that hands the file key back verbatim — a real type would wrap it under a key it owns.

moonbit
struct Example {} impl @spec.Recipient for Example with wrap(self, file_key~, random~) { ignore(self) ignore(random) @spec.Stanza::new(kind="example.com/plain", args=[], body=file_key.to_owned()) } impl @spec.Identity for Example with unwrap(self, stanza~) { ignore(self) if stanza.kind == "example.com/plain" { return Some(stanza.body) } None } fn custom_example() -> Unit raise @spec.Refused { let file = @moonseal.seal( [Example::{}], b"the quick brown fox\n", random=@moonseed.Replay::new(Bytes::make(64, 0x21)), ) catch { _ => abort("no") } println("opened: " + @utf8.decode_lossy(@moonseal.open([Example::{}], file))) }
output
--- custom recipient ---
opened: the quick brown fox
Interoperability note. Anything moonseal seals is a plain age v1 file. The armored block above, and every sealed file in this guide, opens with age, rage, and any other conforming implementation — and their files open here. The CI exchanges a sealed file with age and rage on every run.
